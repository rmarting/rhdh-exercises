This guide delivers a hands-on Red Hat Developer Hub workshop including some of the most common
configuration on Red Hat OpenShift.

Participants will configure authentication, catalog discovery, RBAC, software templates, dynamic plugins, TechDocs,
high availability, monitoring, notifications, Orchestrator, AI integrations, and enterprise extensions step by step.

== Timing and schedule

This workshop is designed to be completed in approximately one day.

== Technical requirements

This repository was tested and verified in the following environment provided by the link:https://demo.redhat.com/[Red Hat Demo Platform]:

* link:https://catalog.demo.redhat.com/catalog/all?item=babylon-catalog-prod%2Fpublished.ocp4-cluster.prod[Red Hat OpenShift Container Platform Cluster (Multi-Cloud),window="_blank"]

NOTE: You must have `cluster-admin` privileges to install the different operators required for this technical exercise.

=== Environment setup

Order a https://catalog.demo.redhat.com/catalog/babylon-catalog-prod/order/published.ocp4-cluster.prod[Red Hat OpenShift Container Platform Cluster (Multi-Cloud),window="_blank"] from the Red Hat Demo Platform with the following options:

[cols="1,2",options="header"]
|===
| Option | Value

| Activity
| Practice / Enablement

| Purpose
| Conduct internal training/enablement

| Cloud Provider
| cnv

| OpenShift Version
| 4.21

| Cluster Size
| sno

| Create Users on Cluster
| Unchecked

| Enable OpenShift Lightspeed
| Unchecked
|===

IMPORTANT: Order your cluster *before* the lab begins -- provisioning can take up to 60 minutes.
Once provisioning is complete you will receive an email with your cluster credentials and console URL.

=== Software versions

The content of this repo was tested:

* Red Hat OpenShift Container Platform {ocp_version}
* Red Hat Developer Hub Operator {rhdh_version}
* GitLab Operator {gitlab_operator_version}
* GitLab Server {gitlab_server_version}
* Web browser (Chrome, Firefox, or Edge)

=== Environment access

Participants need:

* OpenShift cluster with `cluster-admin` for operator installation
* Terminal access (`oc`, `envsubst`, `git`)
* GitLab `root` user access (password from cluster secret)
* Namespace `{rhdh_namespace}` for the Red Hat Developer Hub instance

=== Network requirements

* Cluster ingress domain
* Access to GitLab, Red Hat Developer Hub route, and OpenShift console URLs
* OpenShift Data Foundation for TechDocs
