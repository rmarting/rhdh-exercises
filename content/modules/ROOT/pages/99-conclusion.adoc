== Workshop summary

You configured Red Hat Developer Hub on OpenShift with GitLab integration across twenty hands-on modules:

* **Foundation** — Operators, GitLab, base Red Hat Developer Hub instance, mandatory secrets and app-config
* **Identity and catalog** — GitLab auth, API integration, project and org autodiscovery
* **Governance and self-service** — RBAC, software templates, component scaffolding
* **Platform extensions** — Dynamic plugins, TechDocs, HA, plugin cache, monitoring, notifications
* **Advanced topics** — Orchestrator, MCP, Lightspeed, external database, CI/CD visibility

Manifests remain in `lab-prep/` (bootstrap) and `./content/modules/ROOT/examples/exercises/` (numbered steps 0–17) for reuse outside Showroom.

* Deployed Red Hat Developer Hub {rhdh_version} with the GitLab provider on OpenShift {ocp_version}
